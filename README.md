# Curriculum Pflegefachfrau / Pflegefachmann

Veröffentlichte Fassung des schulinternen Curriculums der Pflegeschule Neustadt in Holstein
(AMEOS Institut Nord). Die Seite ist **passwortgeschützt**: Der gesamte Inhalt von `index.html`
ist verschlüsselt und nur mit dem Passwort lesbar.

Dieses Repository enthält nur die Seite. Bearbeitet wird das Curriculum in der Seite selbst
(„Datei, Stände und Export“ → „Datei speichern“); die neue Datei wird als `index.html` hier
hochgeladen und ersetzt die alte.

Bitte hier keine unverschlüsselten Fassungen ablegen.
